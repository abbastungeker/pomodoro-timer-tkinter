# Pomodoro Timer - Tkinter

A simple desktop Pomodoro timer built with Python and Tkinter.

The app automatically cycles through work sessions, short breaks, and long breaks while keeping track of completed work sessions using tick marks.

## Features

- 30-minute work sessions
- 5-minute short breaks
- 20-minute long breaks
- Automatic transition between work and break sessions
- Long break after every 4 work sessions
- Session tracking using tick marks
- Reset button to stop and restart the timer
- Dynamic timer labels and colours

## How It Works

The timer follows this cycle:

- Rep 1 → Work
- Rep 2 → Short Break
- Rep 3 → Work
- Rep 4 → Short Break
- Rep 5 → Work
- Rep 6 → Short Break
- Rep 7 → Work
- Rep 8 → Long Break

The cycle then repeats automatically.

## Technologies Used

- Python
- Tkinter
- Math module

## What I Learned

This project helped me practice:

- Building desktop GUIs with Tkinter
- Using `Label`, `Button`, `Canvas`, and `PhotoImage`
- Using `.grid()` for GUI layout
- Creating countdown timers with `window.after()`
- Cancelling scheduled events with `after_cancel()`
- Using modulo `%` to control repeating program logic
- Working with global variables
- Updating Tkinter widgets using `.config()` and `.itemconfig()`
- Creating automatic work/break cycles

1. Clone or download the repository.
2. Make sure Python is installed.
